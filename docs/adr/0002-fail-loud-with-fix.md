# 失败即硬失败，但带上一条可直接执行的修复指令

内置 python 缺包时 harness 零拦截，traceback 原样进上下文；这正是模型绕路换库的触发面。
静默回退到内置会让缺包变成更难发现的静默错误，而裸失败又会把"该干什么"重新交还给模型的自由发挥。

决定：解析出的解释器跑失败时**不隐藏失败**，但错误里附三样东西——当前解释器标识、
缺失模块列表、以及一条精确可执行的修复命令（如 `<interpreter> -m pip install pyyaml`）。
自动安装缺失包实现为**默认关闭**的开关：它会动用户环境，默认不做。

## Consequences

- 错误信息必须短。它每次失败都会进上下文，写长了就是把 token 从"绕路"移到"诊断"。
- 命令必须精确到解释器绝对路径，否则模型会敲到那个商店占位符上，重新触发循环。
