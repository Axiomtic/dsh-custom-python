# 不影射 PATH：shell 归用户，插件只提供一个工具

之前的 ADR-0005 为了让裸命令 `python` 也能落到用户环境，在前置 PATH 上做了进程级影射。
它解决了"模型顺口敲 python 撞商店占位符"的循环，但代价一路暴露：

- 影子是进程级的，和"按会话"的语义天然冲突（一个会话的选择会改变别的会话的 shell）；
- 依赖 `process.env.PATH` 这种非官方约定，升级即可能失效；
- 只要 agent 真正开始敲 shell，就已经是在做一次显式选择，插件再去改它的结果属于越界。

决定：**移除 PATH 影射**。插件只提供一个 `python` 工具，并让它的描述明确"优先用它，而不是在 shell 里跑"。
shell 里的 `python` 保持系统原状 —— 系统里有就有，是商店占位符就是商店占位符。

## Consequences

- "模型在 shell 里敲 python 撞死"这个循环不再由插件兜住。这是刻意接受的：它的修复成本（全局副作用 + 语义混乱）
  高于它省下的两三次调用。
- 会话隔离变得干净：工具按会话、shell 按系统，不存在第三条隐式通道。
- 少了一个模块、一套测试、一个配置项。

Supersedes ADR-0005.
